# Android module

Kotlin + Jetpack Compose. Build with `./gradlew assembleDebug` on a machine that has Java 17, Android SDK Platform 35, internet access for the initial Gradle distribution, and Android build tools installed. On Windows use `gradlew.bat assembleDebug`. Then configure the real HTTPS API address in the app's sign-in screen or replace the default development address before building a release.

The launcher project is source-only; it does not include a prebuilt APK.
